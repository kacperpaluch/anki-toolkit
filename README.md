# Anki Toolkit Add-ons

Zestaw niezależnych dodatków Anki. Każdy można instalować i aktualizować osobno.

| Dodatek | Funkcja |
|---|---|
| Content | Generowanie AI, Batch API, workflowy, wymowa ze słowników, TTS oraz rozdzielanie pól. |
| Learning | Tworzenie talii filtrowanych z presetów powtórek. |
| Audio Normalizer | Normalizacja mediów przez ffmpeg oraz opcjonalny watcher nowych plików. |
| Audio Embed | Zamiana `[sound:...]` na osadzone odtwarzacze HTML5. |
| HTML Cleanup | Normalizacja `&nbsp;` i `<div>` przy dodawaniu notatek lub w całej kolekcji. |
| Field Hider | Ukrywanie wybranych pól wyłącznie w oknie Dodaj. |
| Local Sources | Lokalne bazy Oxford 5000 i SuperMemo, przyciski OX/SM w edytorze. |
| Integrations | Kolejka n8n z adresem domowym/Tailscale, panel słowników i Web Bridge. |

Źródła dodatków są w katalogach `anki_toolkit_*`; każdy zawiera własne README,
`llm-context.md`, konfigurację UI i instrukcje. Dane użytkownika, klucze API,
media, logi i cache są ignorowane przez Git.
