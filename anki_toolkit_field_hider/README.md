# Anki Toolkit: Field Hider

Samodzielny dodatek ukrywający wybrane pola tylko w oknie **Dodaj**. Podczas
edycji istniejących notatek i w przeglądarce pola pozostają widoczne.

## Instalacja

Skopiuj ten katalog jako osobny dodatek Anki. Nie włączaj równocześnie starego
modułu `field_hider` w scalonym dodatku Anki Toolkit — oba dodatki rejestrują te
same hooki edytora.

## Konfiguracja

Otwórz **Narzędzia → Anki Toolkit: Field Hider…**, wybierz typ notatki i zaznacz
pola do ukrycia. Nie wymaga to edycji plików konfiguracyjnych.

Przycisk **👁** w oknie Dodaj tymczasowo pokazuje lub ukrywa te pola. Nie zmienia
konfiguracji ani danych notatki.
