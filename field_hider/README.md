# Ukrywanie pól (`field_hider/`)

Ukrywa wybrane pola tylko w oknie **Dodaj**. Podczas edycji istniejących
notatek i w przeglądarce pola pozostają widoczne.

W **Narzędzia → Anki Toolkit → Ustawienia… → Ukrywanie pól** wybierz typ
notatki i zaznacz pola do ukrycia.

Przycisk **👁** w oknie Dodaj tymczasowo pokazuje lub ukrywa te pola. Nie zmienia
konfiguracji ani danych notatki.
